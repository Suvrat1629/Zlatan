# Parity fixtures & gates

Model version: **`tcn_v1_2026-08-29_419ee90`** (from `sih-26168-model`).

| File | What |
| --- | --- |
| `testset.npz` | 97 windows, hard-case biased. Keys: `raw_inputs [97,50,9]`, `raw_high_rate` (== `raw_inputs`), `model_inputs [97,50,7]` (features, pre-norm), `model_inputs_norm`, `keras_outputs [97,1]`, `tflite_outputs [97,1]`. |
| `norm.json` | Per-channel standardisation mean/std (mirrored inline in `ParityGatesTest`). |
| `decimate.py.reference` | The model team's decimation reference — `Decimator` is its Kotlin twin. |

## The gates

| Gate | Where | Runs on | Checks |
| --- | --- | --- | --- |
| **G2** | `ParityGatesTest.g2_*` | JVM (`./gradlew :engine:test`) | `FeatureExtractor` == `preprocess.py` |
| **G2a** | `ParityGatesTest.g2a_*` | JVM | `Decimator` box-average == `decimate.py` definition |
| **G3a** | `ParityGatesTest.g3a_*` | JVM | `Normalizer` == `preprocess.py normalize()` |
| **G0** | `TfliteSpeedEstimator.init` → `ModelSelfTest.run` | device | manifest `self_test` vector → `26.7037 m/s` (± 0.001). App refuses to start on failure. |
| **G3** | `android-model` instrumented test | device/emulator | normalise + interpreter == `keras_outputs` (± 1e-3) |
| **G4** | `android-model` instrumented test | device | `raw_inputs` → full Kotlin pipeline on device == `keras_outputs` (± 1e-3) — **the de-risking milestone** |

## Still open

- **G2a has no Python-twin fixture.** `raw_high_rate == raw_inputs` because IO-VNBD is
  natively 10 Hz. A real high-rate → 10 Hz fixture generated by `decimate.py` would let
  G2a compare against the reference, not just the definition. Ask the model team.
- **G1** (Keras vs Python-TFLite) is the model team's gate — PASS, max abs diff 5.7e-6
  (`sih-26168-model/export_artifacts.py`).

## Refreshing on a new model version

The model team ships `.tflite` + `norm.json` + `manifest.json` as a matched triple.
On a version bump: replace `testset.npz` + `norm.json` here, update the inline mean/std in
`ParityGatesTest`, update `app/src/main/assets/engine.manifest.json`, re-run G2/G2a/G3a +
the device gates.
